## Цель
Пользователь всегда узнаёт, что будильник не прозвенел: после автостопа (уже сделано в M1) и после пропуска > 10 мин при перепланировании (выключенный телефон, перевод часов вперёд). Остальные S-пункты — в бэклоге.

## Архитектура этапа
Что уже есть: `AlarmNotifications.missed()`, канал `MISSED`, показ при автостопе в `RingingService` (тег `missedTag(id)`, отмена при новом звонке), тесты.

Чего нет: `AlarmEngine.restoredPlan` (ветка `else`) молча выключает разовый будильник (`disableIfMissedOneShot`) или переносит повторяющийся. Движок в `:core:domain` без Android, поэтому:
* порт `MissedAlarmNotifier { fun onMissed(alarm: Alarm, missedAt: Instant) }` в `:core:domain` (по аналогии с `AlarmEventLog`), по умолчанию no-op;
* реализация в `:core:alarm` показывает `AlarmNotifications.missed()` с тем же тегом/ID, Hilt-биндинг в `AlarmModule`;
* вызывается только для `stored.enabled`, `!hasFiredFor(next)`, `next` в прошлом и старше `LATE_GRACE` (10 мин). Не дублируется при повторных `rescheduleAll`: после обработки `nextTriggerAt` сдвигается, условие больше не выполняется.
* без POST_NOTIFICATIONS — тихо ничего не делаем (баннер здоровья уже сообщает об этом).

Новых ADR нет. Флаг не нужен: это часть ядра надёжности (FR-FLAG-4).

### M7-T01 — Порт и вызов из движка 🔔
**Приёмка:**
- [x] enabled разовый, пропущен > 10 мин → выключается **и** вызван `onMissed`;

## Добавлено по ходу
* Ревью: уведомление вызывается после `applySchedule` (через `Plan.missedAt`), чтобы сбой записи не дублировал его; добавлены тесты hasFiredFor, выключенный с устаревшим триггером, сбой записи. Принято как допущение: после `degraded`-срабатывания без `lastFiredAt` возможно ложное «пропущен» при позднем `rescheduleAll` (поведение для разового будильника уже было). Текст уведомления берёт `alarm.time`, не `missedAt`.
* T-test (эмулятор): запуск `balarm_api37` без окна не дошёл до `boot_completed` за ~15 мин (машина загружена, `adb shell` не отвечал), эмулятор остановлен. Unit/Robolectric зелёные; сценарий на эмуляторе (пропуск при смене времени, R3, R6) — не выполнен, повторить.
