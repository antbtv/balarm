## Надёжность и разрешения
| ID | Функция | Приоритет |
|---|---|---|
| F-REL-01 | Точные будильники через `AlarmManager.setAlarmClock()` | M |
| F-REL-02 | Восстановление после перезагрузки, **в т.ч. до разблокировки (Direct Boot)** | M |
| F-REL-03 | Восстановление после смены времени/часового пояса/обновления приложения | M |
| F-REL-04 | Full-screen звонок на экране блокировки | M |
| F-REL-05 | Показ поверх других приложений (overlay) | M |
| F-REL-06 | Онбординг разрешений: уведомления → точные будильники → FSI → overlay → батарея → автозапуск OEM | M |
| F-REL-07 | Экран «Здоровье будильника»: что из разрешений отозвано, кнопки исправления | M |
| F-REL-08 | Будильник звучит даже при беззвучном режиме / DND (поток ALARM) | M |
| F-REL-09 | Пропущенный будильник (телефон был выключен) → уведомление | S |
| F-REL-10 | Защита от выключения телефона / удаления приложения | W |
