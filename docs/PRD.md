## 1. Видение

**Balarm** — бесплатный Android-будильник в стиле Alarmy, который **невозможно проспать**: чтобы выключить его, нужно решить утреннюю головоломку, а вместо рекламы — мотивирующая цитата на весь день.

### 1.1 Проблема
* Обычный будильник выключается «во сне» за 1 секунду.
* Alarmy решает это, но ключевое — за подпиской и с рекламой.
* Будильники на Android нередко не срабатывают из-за энергосбережения, перезагрузок ночью (автообновление ОС) и отозванных разрешений.

### 1.2 Цели
| # | Цель | Метрика |
|---|---|---|
| G1 | Будильник срабатывает всегда | 100 % срабатываний в тестовой матрице (§9), включая перезагрузку до разблокировки |
| G2 | Нельзя отключить не проснувшись | Отключение только через миссию; бездействие в миссии возвращает звук |
| G3 | Утро начинается с мотивации | Цитата на экране звонка/миссии/«Доброе утро» |
| G4 | Ощущение «как Alarmy» | Тёмный UI, крупные цифры, красный акцент, миссии полноэкранные |
| G5 | Без рекламы, без аккаунтов, без сети | Приложение работает полностью офлайн, не требует INTERNET в MVP |

### 1.3 Не-цели (v1)
Трекинг сна, звуки для сна, облачная синхронизация, аккаунты, реклама, подписки, iOS, Wear OS, фото-миссия, защита от выключения телефона.

### 1.4 Персоны
* **«Совушка» Аня, 24** — трижды откладывает будильник, опаздывает. Нужна миссия, которая реально будит.
* **«Дисциплина» Макс, 31** — встаёт в 6:00 на тренировку, хочет мотивирующую цитату и серию дней.
* **«Параноик» Олег, 40** — у него уже был случай, когда телефон ночью перезагрузился и будильник не прозвенел. Главное — надёжность.

## 3. Функциональные требования

Формат: `ID` — требование. **AC** — критерии приёмки (Given/When/Then сокращённо).

### 3.1 Список будильников (главный экран)
* **FR-LIST-1** Показывает все будильники, отсортированные по времени; каждый — карточка: время (крупно), AM/PM при 12h, метка, дни повтора («таблетки» Пн–Вс, активные подсвечены), иконки миссий, тумблер.
* **FR-LIST-2** Шапка: «Следующий будильник через 7 ч 12 мин» / «Нет активных будильников».
* **FR-LIST-3** FAB «+» (красный круг) — создать будильник.
* **FR-LIST-4** Тап по карточке — редактор; долгий тап / свайп — меню: удалить, дублировать (C), пропустить следующий (S).
* **FR-LIST-5** Если какое-либо критичное разрешение отозвано — баннер сверху «Будильник может не сработать → Исправить» (ведёт на экран здоровья, FR-REL-7).
* **AC:** выключение тумблера немедленно отменяет запланированный `AlarmManager`-интент (проверка: `adb shell dumpsys alarm | grep <package>`).

### 3.2 Редактор будильника
* **FR-EDIT-1** Колесо выбора времени (часы/минуты, бесконечная прокрутка, haptic на каждом шаге). Формат 24h/12h — по системной настройке.
* **FR-EDIT-2** Повтор: 7 кнопок-дней + чипы «Будни», «Выходные», «Каждый день». Ни один день не выбран = разовый будильник.
* **FR-EDIT-3** (S) Разовый будильник на дату — календарь.
* **FR-EDIT-4** Метка (до 40 символов).
* **FR-EDIT-5** Звук: выбор мелодии (→ 3.4), громкость (слайдер 0–100 %, превью звука во время перетаскивания), плавное нарастание (выкл/15/30/60 с), вибрация (вкл/выкл).
* **FR-EDIT-6** Миссия: «Без миссии» / одна из доступных; для каждой — настройки и кнопка «Попробовать» (превью без звука). (S) до 3 миссий подряд.
* **FR-EDIT-7** Snooze: выкл / интервал 1,3,5,10,15,20,30 мин; лимит 1,2,3,5,10,∞.
* **FR-EDIT-8** Цитаты: показывать цитату вкл/выкл; (S) источник — все / только мои / категория.
* **FR-EDIT-9** (S) Wake-up check: выкл / через 3/5/10 мин.
* **FR-EDIT-10** Кнопки «Сохранить», «Тест» (запуск полного сценария звонка через 5 с), «Удалить» (для существующего).
* **FR-EDIT-11** При сохранении — тост «Будильник зазвонит через 7 ч 12 мин».
* **AC:** несохранённые изменения при «Назад» → диалог «Отменить изменения?».

### 3.3 Срабатывание (экран звонка)
* **FR-RING-1** В назначенное время: включается экран, поверх экрана блокировки и поверх любых приложений показывается полноэкранный экран звонка; звук на потоке `USAGE_ALARM`; вибрация по настройке.
* **FR-RING-2** Экран звонка: текущее время (огромное), дата, метка, цитата (если включено), кнопка «Отложить (осталось N)» и большая кнопка «Отключить».
* **FR-RING-3** «Отключить» при наличии миссии → экран миссии; без миссии → сразу отключение.
* **FR-RING-4** Кнопки громкости и кнопка питания **не** отключают будильник, если есть миссия (громкость игнорируется; экран остаётся/переоткрывается).
* **FR-RING-5** Если пользователь свернул экран звонка (Home/Recents) — звук продолжается, через ≤3 с экран возвращается наверх (при наличии overlay-разрешения); ongoing-уведомление всегда присутствует и ведёт на экран звонка.
* **FR-RING-6** Автостоп: если никто не взаимодействует 30 мин — будильник замолкает, уведомление «Пропущенный будильник». (настройка в глобальных настройках: 5/10/15/30 мин/никогда).
* **FR-RING-7** Если одновременно срабатывают 2 будильника — второй встаёт в очередь и начинает звонить после завершения первого (не более одного экрана звонка).
* **FR-RING-8** Если идёт телефонный звонок — будильник вибрирует/тихо звучит и полноценно начинает после окончания вызова.
* **FR-RING-9** После отключения → экран «Доброе утро» (S; в MVP — просто закрытие с тостом и цитатой).
* **AC:** время от срабатывания `AlarmManager` до начала звука ≤ 2 с на эталонном устройстве, в т.ч. в Doze (`adb shell dumpsys deviceidle force-idle`).

### 3.4 Мелодии
* **FR-SND-1** Встроенные: 8–12 мелодий (свободная лицензия CC0/собственные), хранятся в `res/raw`.
* **FR-SND-2** «Добавить мелодию»: системный пикер (SAF, `ACTION_OPEN_DOCUMENT`, audio/*). Файл **копируется** во внутреннее хранилище приложения (device-protected storage, см. §6.3), чтобы работать при Direct Boot и после удаления исходника. Лимит 20 МБ на файл.
* **FR-SND-3** Библиотека: прослушать, переименовать, удалить (если мелодия используется — будильники переключаются на встроенную по умолчанию, с предупреждением).
* **FR-SND-4** (S) Системные рингтоны через `RingtoneManager`.
* **FR-SND-5** Резервный звук: если мелодию не удалось открыть/воспроизвести за 1 с — играет встроенная мелодия по умолчанию; если и она не играет — `ToneGenerator` + вибрация.
* **FR-SND-6** Плавное нарастание громкости от 10 % до целевой за выбранное время.
* **FR-SND-7** Громкость будильника выставляется на `STREAM_ALARM` на время звонка и восстанавливается после.

### 3.5 Миссии
Общие правила:
* **FR-MIS-1** Миссия — полноэкранный экран с прогресс-баром «2/5» и таймером бездействия.
* **FR-MIS-2** На время миссии звук приглушается до 30 % (настраиваемо); при бездействии > 15 с (настр. 10–60) — звук снова на 100 %, прогресс текущей задачи сбрасывается.
* **FR-MIS-3** Выйти из миссии без выполнения нельзя (Back → возврат на экран звонка, звук снова громкий).
* **FR-MIS-4** Каждая миссия реализует общий контракт (`MissionType`, `MissionConfig`, `MissionState`, `MissionScreen`) — добавление новой миссии не требует правок ядра (см. скилл `add-mission`).
* **FR-MIS-5** Режим превью: та же миссия без звука, с кнопкой «Закрыть».

| Миссия | Правила | Настройки | Приёмка |
|---|---|---|---|
| **Math** | Генерация примеров по уровню: L1 `a+b` (1–2 знака); L2 `a+b-c`; L3 `a×b + c`; L4 `a×b + c×d` (2 знака); L5 `(a×b) - c + d` (3 знака). Ответ — целое, может быть отрицательным (с L3). Цифровая клавиатура своя (крупная). Неверный ответ → тряска поля, новый пример не выдаётся. | уровень 1–5, кол-во 1–10 | Генератор детерминирован по seed (unit-тесты), все ответы в int-диапазоне |
| **Memory** | Показ подсвеченных клеток 2–3 с, затем пользователь отмечает их. Ошибка → раунд заново с новой раскладкой. | сетка 3×3/4×4/5×5, раунды 1–5 | Кол-во клеток растёт с размером сетки |
| **Typing** | Показывается цитата (≤ 120 символов); ввести её точно (регистр и пунктуация — нестрого, настраивается). Ошибочные символы подсвечиваются красным. | кол-во фраз 1–3, строгость | Сравнение нормализованных строк покрыто unit-тестами |
| **Shake** (S) | Счётчик встряхиваний (акселерометр, порог ≈ 2.7g, debounce 250 мс) | кол-во 10–200, чувствительность | Тест на эмуляторе через virtual sensors |

### 3.6 Цитаты
* **FR-QOT-1** Встроенная библиотека ≥ 150 цитат RU + ≥ 150 EN (public domain / собственный перевод; поле `author`, `category`, `lang`). Поставляется как asset JSON и сидится в БД при первом запуске и при обновлении версии пакета цитат.
* **FR-QOT-2** Экран «Цитаты»: список с поиском, фильтр по категории, вкладки «Все / Мои / Избранное».
* **FR-QOT-3** Добавить/редактировать свою цитату: текст (≤ 300), автор (опц.), категория. Встроенные можно скрыть, но не удалить.
* **FR-QOT-4** Выбор цитаты для звонка: случайная с учётом весов (избранные ×3), без повторов за последние 14 показов.
* **FR-QOT-5** Язык встроенных цитат — по языку приложения; настройка «Показывать цитаты на: RU / EN / обоих».
* **FR-QOT-6** (C) Импорт/экспорт JSON/TXT.

### 3.7 Онбординг и разрешения
Показывается при первом запуске, пошагово, по одному разрешению на экран: иллюстрация, «Зачем это нужно», кнопка «Разрешить», «Позже» (кроме критичных). Порядок:

| Шаг | Разрешение / настройка | API | Критично | Проверка статуса |
|---|---|---|---|---|
| 1 | Уведомления | `POST_NOTIFICATIONS` (API 33+) runtime | да | `NotificationManagerCompat.areNotificationsEnabled()` |
| 2 | Точные будильники | `USE_EXACT_ALARM` (авто) + `SCHEDULE_EXACT_ALARM` (API 31–32) | да | `AlarmManager.canScheduleExactAlarms()` |
| 3 | Полноэкранные уведомления | `USE_FULL_SCREEN_INTENT` (API 34+ может быть отозвано) → `Settings.ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT` | да | `NotificationManager.canUseFullScreenIntent()` |
| 4 | Поверх других приложений | `SYSTEM_ALERT_WINDOW` → `Settings.ACTION_MANAGE_OVERLAY_PERMISSION` | да (для FR-RING-5) | `Settings.canDrawOverlays()` |
| 5 | Отключить оптимизацию батареи | `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` → `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | да | `PowerManager.isIgnoringBatteryOptimizations()` |
| 6 | Автозапуск / фоновая активность (Xiaomi, Huawei/Honor, Oppo/Realme, Vivo, Samsung «спящие приложения») | OEM-интенты с fallback на экран настроек приложения | рекомендовано | не проверяемо → чек-бокс «Я сделал» + ссылка на dontkillmyapp.com |
| 7 | (опц.) Звук в режиме «Не беспокоить» | подсказка: будильники по умолчанию разрешены | нет | `NotificationManager.getCurrentInterruptionFilter()` |

* **FR-REL-7 Экран «Здоровье будильника»** (Настройки → Надёжность): список всех пунктов с ✅/⚠️, кнопка «Исправить» у каждого, кнопка «Тестовый будильник через 1 минуту».
* При каждом `onResume` главного экрана статусы перепроверяются; при отзыве критичного — баннер (FR-LIST-5).
* Возврат из системных настроек обратно в онбординг — автоматически отмечает шаг.

### 3.8 Надёжность (детально)
* **FR-REL-1** Планирование — только `AlarmManager.setAlarmClock(AlarmClockInfo, PendingIntent)` (не подвержен Doze, показывает иконку будильника в статус-баре). `showIntent` → главный экран.
* **FR-REL-2** Перезагрузка: ресиверы `LOCKED_BOOT_COMPLETED` (directBootAware) и `BOOT_COMPLETED` перепланируют все активные будильники. Расписание и мелодии лежат в **device-protected storage**, поэтому будильник сработает **даже если телефон перезагрузился ночью и не был разблокирован**.
* **FR-REL-3** Ресиверы `TIME_SET`, `TIMEZONE_CHANGED`, `MY_PACKAGE_REPLACED`, `ACTION_SCHEDULE_EXACT_ALARM_PERMISSION_STATE_CHANGED`, `LOCALE_CHANGED` (для текста уведомлений) → перепланирование.
* **FR-REL-4** Будильник хранит время как «локальное время + дни недели»; момент срабатывания вычисляется через `java.time` в текущей зоне → корректен при переходе на летнее/зимнее время (несуществующее время 02:30 → 03:00; дублированное → первое наступление).
* **FR-REL-5** Звонок проигрывается в foreground service (тип по ADR-002: `mediaPlayback` или `systemExempted`), с `WakeLock` на время старта; экран — Activity с `setShowWhenLocked(true)`, `setTurnScreenOn(true)`, запущенная через full-screen intent и дублирующе через `startActivity` при наличии overlay-разрешения.
* **FR-REL-6** Пропущенный будильник: если при загрузке обнаружен будильник, время которого прошло < 2 ч назад и он не отработал — уведомление «Пропущен будильник 07:00» (S).
* **FR-REL-8** Звук — `AudioAttributes.USAGE_ALARM`, `CONTENT_TYPE_SONIFICATION`; audio focus `AUDIOFOCUS_GAIN_TRANSIENT`.
* **FR-REL-9** Наушники: звук идёт через динамик и наушники одновременно (как у системного будильника, поведение USAGE_ALARM) — зафиксировать в тестах.

### 3.9 Настройки (глобальные)
Тема (тёмная/светлая/системная; по умолчанию тёмная), язык, формат цитат, автостоп звонка, таймер бездействия миссий, громкость миссии, первый день недели, «Здоровье будильника», о приложении/лицензии мелодий, (C) бэкап/восстановление.

### 3.10 Экран «Доброе утро» (S)
После отключения: приветствие по времени суток, дата, цитата крупно (кнопка «в избранное»), «Вы проснулись с N-й попытки», кнопка «Закрыть». (C) погода.

## 4. UX / UI

### 4.1 Навигация
Нижняя навигация: **Будильники** · **Цитаты** · **Настройки**. (C) «Отчёт».
Полноэкранные потоки вне навигации: Онбординг, Редактор, Выбор мелодии, Настройки миссии, Звонок, Миссия, Доброе утро.

### 4.2 Дизайн-система «в стиле Alarmy»
Вдохновляемся стилем, **не копируем** логотипы, иконки, иллюстрации и мелодии Alarmy.

| Токен | Тёмная | Светлая |
|---|---|---|
| `background` | `#0E0F14` | `#F5F6FA` |
| `surface` (карточки) | `#1B1D26` | `#FFFFFF` |
| `surfaceVariant` | `#262936` | `#ECEEF4` |
| `primary` (акцент) | `#FF4D4F` | `#F0383B` |
| `onPrimary` | `#FFFFFF` | `#FFFFFF` |
| `textPrimary` | `#FFFFFF` | `#14161F` |
| `textSecondary` | `#8B8FA3` | `#6B6F80` |
| `success` | `#3DD68C` | `#1FAF6A` |
| `warning` | `#FFB020` | `#E08E00` |

* **Типографика:** время в карточке — 44sp Bold, на экране звонка — 96sp Bold (моноширинные цифры, `fontFeatureSettings = "tnum"`); заголовки 22sp SemiBold; текст 16sp.
* **Формы:** карточки radius 20dp, кнопки radius 16dp высотой 56dp, FAB 64dp круглый.
* **Анимации:** пульсация кнопки «Отключить», тряска при ошибке в миссии, haptic на колесе времени.
* **Доступность:** контраст ≥ 4.5:1, минимальная зона тапа 48dp, TalkBack-описания, поддержка шрифта 200 %.
* Реализация — Jetpack Compose + Material 3 с кастомной `ColorScheme`; все токены в `core/designsystem`.

## 5. Нефункциональные требования

### 6.1 Стек

### 6.2 Модули
```

```
Архитектурный паттерн UI — MVVM/UDF (`UiState` + `onEvent`), однонаправленный поток данных.

### 6.3 Хранение и Direct Boot
* Room-БД и DataStore создаются в `context.createDeviceProtectedStorageContext()`; Application и компоненты будильника — `android:directBootAware="true"`.
* Кастомные мелодии копируются в device-protected `files/sounds/`.
* Данные не секретные (время, текст цитат), поэтому device-protected хранение допустимо — фиксируется в ADR-001.

### 6.4 Модель данных (черновик)
```
Alarm(id, hour, minute, daysOfWeek: Set<DayOfWeek>, date: LocalDate?, label,
      enabled, soundId, volume, fadeInSec, vibrate,
      snoozeIntervalMin, snoozeLimit, missions: List<MissionConfig>,
      showQuote, quoteSource, wakeUpCheckMin, skipNextUntil: Instant?)
AlarmRuntimeState(alarmId, nextTriggerAt, snoozeCount, isRinging, lastFiredAt)
Sound(id, title, type: BUILTIN|CUSTOM|SYSTEM, uri/path, durationMs)
Quote(id, text, author, category, lang, isBuiltin, isHidden, isFavorite, lastShownAt)
MissionConfig = sealed: Math(level,count) | Memory(grid,rounds) | Typing(count,strict) | Shake(count,sens)
```

### 6.5 Поток срабатывания
```
setAlarmClock ─► AlarmReceiver (directBootAware)
   └─► startForegroundService(RingingService)   // FGS-исключение для exact alarm
         ├─ WakeLock, AudioPlayer(fade-in), Vibrator
         ├─ Notification(fullScreenIntent → RingingActivity, CATEGORY_ALARM)
         └─ if canDrawOverlays → startActivity(RingingActivity)
RingingActivity ─► Dismiss ─► MissionHost ─► success ─► RingingService.stop()
                                                   └─► schedule next / wake-up check
```

## 10. Риски
| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| OEM убивает приложение | высокая | критично | `setAlarmClock`, батарея, автозапуск-гайд, экран здоровья, тест R18 |
| FSI отозван на Android 14+ | средняя | высокое | проверка `canUseFullScreenIntent`, overlay как второй путь, heads-up уведомление с громким звуком как третий |
| Ограничения старта FGS (Android 12+/14+/15) | средняя | критично | старт только из exact-alarm-ресивера (исключение), правильный `foregroundServiceType`, ADR-002 |
| Direct Boot забыт в каком-то компоненте | средняя | критично | чек-лист ревьюера, тест R3 |
| Google Play отклонит restricted-разрешения | низкая | среднее | приложение — будильник по сути; корректные декларации |
| Лицензии на мелодии/цитаты | средняя | среднее | только CC0/public domain, файл `docs/LICENSES.md` |

## 11. Открытые вопросы
1. Имя пакета (`applicationId`) — предлагается `com.antbtv.balarm`.
2. Публикация в Google Play или только личное использование (влияет на restricted-разрешения и M8).
3. Источник встроенных мелодий (сгенерировать / freesound CC0).
4. Нужна ли статистика (F-STA-01) раньше v1.x.

## 12. Глоссарий
**Миссия** — задание для отключения будильника. **FSI** — full-screen intent. **Direct Boot** — состояние после перезагрузки до первой разблокировки, когда доступно только device-protected хранилище. **Wake-up check** — повторная проверка, что пользователь не уснул. **OEM** — производитель устройства со своей оболочкой.
