# Исследование: будильники с «миссиями» (Alarmy и аналоги)

Дата: 2026-09-28. Цель — понять, какой функционал есть у рынка, и отобрать то, что нужно Balarm.

## 1. Alarmy (Delight Room) — эталон

Позиционирование: «самый раздражающий будильник в мире». Отключить будильник можно только выполнив **миссию**.

### 1.1 Миссии (9+ типов, делятся на «мозг / тело / место»)
| Миссия | Суть | Настройки | Категория |
|---|---|---|---|
| Math | Решить N примеров | сложность (5–6 уровней), кол-во задач | мозг |
| Memory | Запомнить и повторить клетки на сетке | размер сетки, кол-во раундов | мозг |
| Typing | Перепечатать фразу (часто мотивирующую) | кол-во фраз | мозг |
| Shake | Потрясти телефон N раз | кол-во (до 999), чувствительность | тело |
| Squat | Сделать N приседаний (акселерометр) | кол-во | тело |
| Walking / Steps | Пройти N шагов | кол-во шагов | тело |
| Photo | Сфотографировать заранее зарегистрированное место (раковина, кофемашина) | эталонное фото | место |
| Barcode / QR | Отсканировать заранее выбранный штрихкод (зубная паста и т.п.) | эталонный код | место |
| Tap challenge | Нажать на кнопку N раз | кол-во | тело |

* **Multiple missions** — до 5 миссий подряд.
* **Wake-up check (anti fall-back-asleep)** — через несколько минут после отключения спрашивает «ты проснулся?»; нет ответа → будильник звонит снова.
* **Лимит повторов (snooze)** — ограничение кол-ва и интервала.
* **Запрет отключения** (premium): блок выключения телефона и удаления приложения во время звонка.

### 1.2 Базовые функции будильника
* Выбор времени (крупное колесо), повтор по дням недели, будильник на конкретную дату.
* Метка (label), громкость, **плавное нарастание громкости**, вибрация, «резервный» звук.
* Встроенные мелодии + свои (музыка с устройства).
* «Пропустить следующее срабатывание» без отключения будильника.
* В шапке — «Следующий будильник через X ч Y мин».
* Предпросмотр / тестовый запуск будильника.

### 1.3 Надёжность
* Онбординг сразу запрашивает: уведомления, «Будильники и напоминания» (exact alarms), показ поверх других приложений, отключение оптимизации батареи, для Xiaomi/Huawei/Samsung — автозапуск.
* Переживает перезагрузку, смену времени/часового пояса, обновление приложения.

### 1.4 Экосистема вокруг утра (в основном premium)
* Morning briefing: погода, новости, гороскоп, цитата дня.
* Sleep sounds, трекинг сна (микрофон/храп), отчёты о сне.
* Статистика: во сколько встал, сколько раз отложил.

### 1.5 Монетизация
Реклама + подписка (премиум-миссии, запрет выключения, трекинг сна, звуки). Это и есть причина делать свой.

### 1.6 Стиль интерфейса Alarmy
* Тёмная тема по умолчанию (почти чёрный/тёмно-синий фон), карточки со скруглёнными углами.
* Ярко-красный/коралловый акцент (FAB «+», активные тумблеры, кнопки миссий).
* Огромные жирные цифры времени; дни недели маленькими «таблетками».
* Нижняя навигация (Будильник / Сон / Утро / Отчёт / Настройки).
* Экран звонка: крупное время, дата, большая кнопка «Отключить» и «Отложить» внизу.
* Экран миссии: полноэкранный, прогресс «1/3», таймер бездействия (после N сек без действий громкость снова на максимум).

## 2. Аналоги (кратко)
| Приложение | Чем интересно |
|---|---|
| **Sleep as Android** | CAPTCHA-миссии (математика, QR/NFC, смех, «овцы»), умное пробуждение по фазам сна, плавная громкость, огромная настройка. |
| **Challenges Alarm Clock** | Миссии-игры, фото, встряхивание, «поймай кнопку». |
| **AlarmMon** | Игровые миссии с персонажами. |
| **I Can't Wake Up!** | 8 типов задач, в т.ч. сортировка, пазл «3×3», повтор узора. |
| **Google Clock** | Эталон надёжности (AOSP DeskClock): `setAlarmClock`, direct boot, full-screen intent; «Sunrise» (подсветка). |

## 3. Выводы
1. Ядро ценности — **надёжность** (будильник обязан сработать всегда) + **миссии** (невозможно отключить «во сне»).
2. Главные технические риски — ограничения Android 12–16: exact alarms, full-screen intent, фоновый старт activity/FGS, агрессивные OEM-энергосбережения, **direct boot** (перезагрузка ночью до разблокировки).
3. Самые ценные и дешёвые миссии для старта: Math, Memory, Typing (идеально сочетается с цитатами), Shake. Photo/QR/Steps — позже.
4. Цитаты — наша фишка: цитата на экране звонка, в миссии Typing и на экране «Доброе утро».
